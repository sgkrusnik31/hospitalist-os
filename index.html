Data & privacy

Your data is saved in this browser's localStorage. It does not automatically synchronize across devices and may be removed if your browser storage is cleared. Download backups periodically; exported files contain your personal work information.

Export backups before uploading a newer app version. No cloud sync is enabled. GitHub Pages cannot privately store your records; secure account-based sync requires a separate backend. No Meditech integration. Calendar is internal only and does not update Google Calendar automatically.

iPhone ↔ desktop synchronization

Not connected yet. GitHub Pages hosts the app files but not your personal records. For secure automatic syncing, a private authenticated database with per-user access rules is required. Until configured, use JSON export/import to transfer records between devices and keep a backup first.

The app will continue to function offline; a future sync service should queue changes offline and resolve edit conflicts on reconnection. Never sync PHI.
